# API RESTful - Tienda Virtual

Backend de tienda virtual construido con Node.js, Express, MongoDB y Mongoose bajo arquitectura MVC.

## Requisitos previos

- Node.js
- MongoDB (configurado con Replica Set `rs0` para soporte de transacciones)

## Instalación y configuración

1. Instalar dependencias:
   ```bash
   npm install
   ```
2. Copiar `.env.example` a `.env` y ajustar las variables de entorno según corresponda.
3. Iniciar el servidor:
   - Desarrollo: `npm run dev`
   - Producción: `npm start`
